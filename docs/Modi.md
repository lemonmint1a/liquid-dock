# 수정 사항

이 저장소는 [sous1345/liquid-dock](https://github.com/sous1345/liquid-dock)을 기반으로 한 수정 버전입니다.
아래는 원본 0.2.0 대비 추가·수정된 내용입니다. (현재 버전 0.2.2)

## 0.2.2 — 최소화된 창 활성화 안정화

- 독에서 최소화된 앱을 눌렀을 때 간헐적으로 창이 앞으로 올라오지 않던 문제를 수정했습니다.
  - `ShowWindowAsync`로 복원을 요청한 직후 `SetForegroundWindow`를 호출하면, 창이 아직 최소화 상태라 활성화가 무시될 수 있었습니다. 이제 동기 `ShowWindow(SW_RESTORE)`로 복원한 뒤 활성화합니다.
  - 최소화된 창이 잠시 포그라운드로 남아 있을 때 "이미 활성화된 창"으로 오인해 다시 최소화하던 문제를 수정했습니다.
  - 포그라운드 스레드뿐 아니라 대상 창의 스레드에도 입력 큐를 연결해 `SetForegroundWindow`/`SetActiveWindow`가 안정적으로 적용되게 했습니다.
  - Windows 포그라운드 잠금 때문에 실패한 경우를 감지해 재시도하며, 필요할 때 짧은 Alt 입력으로 잠금을 풀어 창을 앞으로 가져옵니다. 실패 시 `dock.log`에 진단 로그를 남깁니다.

## 1. 작업표시줄 앱 자동 가져오기 / 고정 앱 복구

- **자동 업데이트 앱의 고정 경로 복구** — Discord, Steam처럼 업데이트할 때마다 실행 파일 경로가 바뀌는 앱은 예전 경로가 사라지면 아이콘이 비거나 클릭해도 실행되지 않았습니다. 이제 시작 메뉴 바로가기와 `AppsFolder`에서 현재 실행 파일과 AUMID를 다시 찾아 고정 정보를 자동으로 복구합니다.
  - Discord: `...\Discord\app-1.0.x\Discord.exe` → `Discord.lnk`(안정적인 런처)
  - Steam: `steamwebhelper.exe` → `Steam.exe` + `Steam.lnk`
- **`ImplicitAppShortcuts` 가져오기** — Steam처럼 자체 AUMID를 쓰는 앱은 `TaskBar` 폴더가 아니라 `ImplicitAppShortcuts`에 고정됩니다. 이제 이 위치도 가져옵니다.
- **패키지 패밀리만 기록된 스토어 앱** — Apple Music처럼 작업표시줄 blob에 패키지 패밀리만 남는 앱도 `AppsFolder`와 대조해 가져옵니다.
- **중복 제거** — Quick Share처럼 `.lnk` 고정과 패키지 고정이 함께 존재하는 항목은 하나만 추가합니다.
- **파일 탐색기 매칭** — 대상 경로가 없는 `.lnk`는 아이콘 위치에서 실행 파일을 얻어, 실행 중인 탐색기 창과 중복되지 않게 합니다.

## 2. 새로 고정한 작업표시줄 앱 동기화

- 기존에는 `pins.txt`가 없을 때만 작업표시줄 앱을 가져와서, 나중에 작업표시줄에 고정한 앱(예: Apple Music)이 독에 나타나지 않았습니다.
- `pinsVersion=3` 마이그레이션에서 현재 작업표시줄에 고정된 앱 중 독에 없는 앱을 한 번 추가합니다.
- 이후 실행부터는 `taskbar_seen.txt`에 이미 본 핀을 기록해, **새로 고정된 앱만 추가**하고 사용자가 독에서 뺀 앱은 다시 추가하지 않습니다.
- 기존 핀 순서와 사용자 설정은 유지하고, 새 앱은 작업표시줄 순서상 이웃한 위치에 삽입합니다.

## 3. 실행 중 앱 매칭 개선

- Discord처럼 버전별 폴더에서 실행되는 앱을 안정적인 런처 경로와 **같은 설치 루트 + 같은 실행 파일명**으로 매칭해 중복 아이콘을 방지합니다.
- 창의 AUMID가 늦게 설정되는 경우 빈 값을 영구 캐시하지 않고 몇 차례 재시도합니다.
- 실행 중인 창이 드러낸 AUMID를 고정 항목에도 반영합니다.

## 4. 모니터별 시작 메뉴

- 시작 버튼을 누른 **독의 모니터**에서 시작 메뉴가 열리도록 수정했습니다. (기존에는 항상 주 모니터)
- 각 작업표시줄의 실제 시작 버튼을 UI Automation으로 사용하며, 작업표시줄이 펼쳐져 있을 때 버튼을 캐시합니다.
- 시작 메뉴를 열 모니터를 지정하기 위해 해당 모니터의 (투명한) 작업표시줄을 포그라운드로 사용합니다.
- **자동 숨김과 작업 영역을 변경하지 않습니다.** 이전 시도에서 작업표시줄을 펼치기 위해 자동 숨김을 껐다 켜면서 모든 창이 위아래로 움직이던 문제를 제거했습니다.
- 다른 모니터에 시작 메뉴가 열려 있으면 닫고 대상 모니터로 전환합니다.
- 시작 메뉴가 이미 열려 있으면 Esc로 닫고, 열림/닫힘 상태가 꼬이지 않도록 짧은 디바운스를 적용합니다.
- Windows 10은 보조 모니터 작업표시줄에 시작 버튼이 없어 Win 키 폴백(주 모니터)으로 동작합니다.
